# 1. Without --acl2-infer, a missing type or index application is an error.

$ cat reverse.remora
;; reverse of a vector, without reverse's type and index arguments
;; (written out, the call is (@reverse (Int) (4 []) [3 1 4 1]))
;; ==
;; output { [1 4 1 3] }
(entry (main)
  (reverse [3 1 4 1]))

$ remora interpret -f reverse.remora
reverse.remora:6:4: error:
Missing type or index application: this function is polymorphic, so it must be given its type or index arguments (t-app, i-app or @) before it is applied:
(reverse_69 (array [4] 3 1 4 1))
(∀ &t_70 (Π $d_71 (Π @s_72 (-> [&t_70 $d_71 @s_72] [&t_70 $d_71 @s_72]))))
Hint: with --acl2-infer, ACL2 infers the missing applications.

# 2. With --acl2-infer, ACL2 attempts to infer the applications and, if
#    successful, passes the elaborated program back to remora; remora writes
#    the elaborated program next to the original as reverse-typed.remora, and
#    then interprets/compiles that elaborated program (which is ordinary
#    Remora code).

$ remora interpret --acl2-infer -f reverse.remora
remora: reverse.remora is missing type or index applications; ACL2 inferred them, in reverse-typed.remora
[1 4 1 3]

$ cat reverse-typed.remora
;; Generated by remora --acl2-infer from reverse.remora: ACL2 inferred its type and index applications.
;; reverse of a vector, without reverse's type and index arguments
;; (written out, the call is (@reverse (Int) (4 []) [3 1 4 1]))
;; ==
;; output { [1 4 1 3] }
(entry (main)
  ((i-app (i-app (t-app reverse Int) 4) (++)) [3 1 4 1]))

# 3. The same through the compiler: Futhark, then C.

$ cat my-last.remora
;; a polymorphic definition whose body calls head and reverse, and a call of
;; it; none of the three calls gives its type or index arguments
;; ==
;; output { 6 }
(def (fun (@my-last (&t) ($n) (v [&t (+ 1 $n)]) : &t)
       (head (reverse v))))

(entry (main)
  (my-last [4 5 6]))

$ remora futhark --acl2-infer --run -f my-last.remora
remora: my-last.remora is missing type or index applications; ACL2 inferred them, in my-last-typed.remora
6

$ cat my-last-typed.remora
;; Generated by remora --acl2-infer from my-last.remora: ACL2 inferred its type and index applications.
;; a polymorphic definition whose body calls head and reverse, and a call of
;; it; none of the three calls gives its type or index arguments
;; ==
;; output { 6 }
(def (fun (@my-last (&t) ($n) (v [&t (+ 1 $n)]) : &t)
       ((i-app (i-app (t-app head &t) $n) (++))
        ((i-app (i-app (t-app reverse &t) (+ 1 $n)) (++)) v))))

(entry (main)
  ((i-app (t-app my-last Int) 2) [4 5 6]))
